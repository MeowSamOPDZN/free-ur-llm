# FreeUr LLM (SML-1)

A **small language model built with just code** — and it runs **100% in your browser**. No servers, no API keys, nothing you type ever leaves the page.

🌐 **Live demo:** https://free-ur-llm.vercel.app/

## What it is

FreeUr LLM has two brains:

1. **Intent brain** (`sml.js`) — understands greetings and reacts instantly:
   - `Hi`, `Hello`, `Hey`, `Yo` → friendly greeting
   - `Bro`, `Bruh` → bro mode
   - `How are you?`, `What's up?` → how-are-you replies
   - plus jokes, facts, riddles, stories, word lookups, and more
2. **Neural brain** (`weights.json` + `sml.js`) — a tiny **character-level transformer**
   (~350K params) trained **from scratch** with PyTorch on 4,000+ chat
   conversations. It generates replies for everything the intent brain
   doesn't catch.

It also ships with **every English word** — `words.txt` (466,550 words) is
loaded as the model's dictionary. Type any single word and it tells you
whether it's real English.

## Try it

Just open `index.html` (or the live demo) and chat:

- `Hi`
- `Bro`
- `How are you?`
- `Tell me a joke`
- `Is "serendipity" a word?`
- `Who made you?`

## Project layout

```
free-ur-llm/
├── index.html        # aesthetic chat UI (MNAI-style dark theme)
├── sml.js            # the engine: vocab loader, intent brain, transformer inference
├── weights.json      # exported neural weights (generated by training)
├── words.txt         # 466,550 English words — the dictionary
└── train/
    ├── train_sml.py       # train the tiny transformer from scratch (PyTorch, CPU)
    ├── build_corpus.py    # builds corpus.txt from seeds + templates
    ├── seed_pairs*.txt    # hand-written conversations
    ├── corpus.txt         # generated training corpus (user:/bot: format)
    └── export_weights.py  # checkpoints/final.pt -> ../weights.json
```

## Train your own

```bash
cd train
python build_corpus.py      # seed pairs -> corpus.txt
python train_sml.py         # train from scratch on CPU (~15-25 min)
python export_weights.py    # export -> ../weights.json
```

Then open `index.html` — your freshly trained brain is live. Edit the seed
pairs to change its personality, add your own Q&A, and retrain.

Model architecture (mirrored exactly between `train_sml.py` and `sml.js`):

- char-level vocab (~60 chars) · `d_model=96` · 3 layers · 3 heads · ctx 96
- learned token + position embeddings, causal attention, GELU MLP, LayerNorm
- KV-cached autoregressive generation in plain JavaScript

## How it works (the honest version)

This is a *real* tiny neural language model, but it's honest about its size:
a few hundred thousand parameters trained on a few thousand short
conversations. It's great at greetings and short chat, and delightfully weird
at everything else — exactly like the classic char-RNN demos. The intent
brain handles the important stuff ("hi", "bro", "how are you?") perfectly
every time.
