how does this work?

LTMWA-1 (Large Text Model without API) has two brains. An intent brain understands greetings ("hi", "bro", "how are you?"), writes code instantly, and reacts to slang. A neural brain — a word-level transformer (~3.4M parameters, int8) trained from scratch on thousands of stories, chats and code examples — generates whole sentences for everything else. It knows every English word plus modern slang (words.txt + slang.txt). No API keys. No servers. Everything runs locally in this page. Code & training scripts are open source on GitHub — train your own LTMWA.
